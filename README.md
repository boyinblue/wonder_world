# 🕹️ Wonder World Arcade Hub

사방에서 몰려오는 벌레를 처치하는 **Crazy Bugs**와 횡스크롤 액션 플랫폼 **Wonder World** 두 가지 게임이 포함된 브라우저 게임 모음입니다.

---

## 🚀 실행 방법

### 방법 1 — 파일 직접 열기 (가장 간단)

1. 이 저장소를 클론하거나 ZIP으로 다운로드합니다.
   ```bash
   git clone https://github.com/boyinblue/wonder_world.git
   ```
2. 폴더 안의 `index.html` 파일을 **크롬 / 엣지 / 파이어폭스** 등 최신 브라우저로 엽니다.
   - Windows: 파일 탐색기에서 `index.html` 더블클릭
   - Mac/Linux: `open index.html` 또는 파일 탐색기에서 더블클릭
3. **Arcade Hub** 화면이 나타나면 원하는 게임의 **플레이** 버튼을 클릭합니다.

### 방법 2 — VS Code Live Server (권장)

1. VS Code에서 폴더를 열고 **Live Server** 확장을 설치합니다.
2. `index.html`에서 우클릭 → **Open with Live Server** 선택.
3. 브라우저에서 자동으로 허브 페이지가 열립니다.

## 🎮 게임 소개

### Crazy Bugs
중앙에서 사방으로 몰려오는 벌레 떼를 마우스로 조준·사격해 최대한 오래 버티는 게임입니다.

| 조작 | 설명 |
|------|------|
| 방향키 | 플레이어 이동 |
| 마우스 이동 | 조준 |
| 마우스 왼쪽 버튼 (홀드) | 발사 |
| `1` | 🔪 나이프 (근접) |
| `2` | 🔫 권총 (단발, 무한) |
| `3` | 🔫 산탄총 (3발 포물선, 픽업 필요) |
| `4` | 🚀 유도탄 (적 자동 추적, 픽업 필요) |
| `5` | ⚡ 연발총 (홀드 연사, 픽업 필요) |

**핵 단축키**

| 키 | 기능 |
|----|------|
| `G` | ★ GOD — 무적 모드 토글 |
| `A` | ∞ AMMO — 무한 탄약 토글 |
| `N` | 💥 NUKE — 화면의 모든 벌레 즉시 폭파 |
| `V` | ⚡ SPEED — 이동속도 2.5배 토글 |

---

### Wonder World
좌우 이동 기반 횡스크롤 액션 플랫폼 게임입니다. 적을 피하거나 처치하며 최대한 멀리 이동해 점수를 올리세요.

| 조작 | 설명 |
|------|------|
| `←` `→` | 이동 |
| `↑` | 점프 |
| `↓` | 앉기 |
| `Space` | 발사 / 나이프 (탄약 없을 때) |
| `1` | 🔪 나이프 (근접) |
| `2` | 🔫 권총 (단발, 무한) |
| `3` | 🔫 산탄총 (픽업 필요) |
| `4` | 🚀 유도탄 (픽업 필요) |
| `5` | ⚡ 연발총 (Space 홀드, 픽업 필요) |

**핵 단축키**

| 키 | 기능 |
|----|------|
| `G` | ★ GOD — 무적 모드 토글 |
| `F` | ∞ AMMO — 무한 탄약 토글 |
| `N` | 💥 NUKE — 화면의 모든 적 즉시 제거 |
| `V` | ⚡ SPEED — 이동속도 2.5배 토글 |
